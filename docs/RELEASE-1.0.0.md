# VoiceWinBridge v1.0.0

首个可交付版本：长按 Win / 右 Alt 说话，松开后落字，语音结束后有条件地恢复原输入法。

## 下载

- 推荐 `VoiceWinBridge-v1.0.0-windows-x64.zip`：EXE、中文使用说明、可选的当前用户自启脚本及 MIT 许可证。
- `VoiceWinBridge.exe`：单独的可执行文件，图标已内嵌；首次使用请先阅读仓库说明。
- 源码可使用 GitHub 自动生成的 Source code 包，或克隆仓库。

需要 Windows 10/11 64 位、.NET Framework 4.8，以及可正常使用语音识别的豆包输入法。无需 Python；发布包不含豆包 DLL、模型、账号、个人配置、日志或备份。

## 本版内容

- 支持独立长按 Win、右 Alt；保留短按 Win 与系统组合键。
- 记录具体 TSF profile，覆盖正常结束、取消、错误和正常退出时的恢复清理。
- 原创多尺寸 EXE / 托盘 / 设置窗口图标，统一 1.0.0 版本信息。
- 可保存的文件日志关闭开关，以及约 1 MB 的两文件轮换。
- 清晰的源码、测试、构建和发布目录，MIT 许可。

## 验证

- 从仅含已提交文件的干净克隆，在 Windows PowerShell 5.1 下构建成功。
- 13 项输入法身份/恢复条件检查及 18 项资源、版本、配置兼容性、日志与 UI 检查通过。
- 已检查实际设置窗口渲染、多尺寸图标和 PE 原生图标资源。
- ZIP 白名单五个文件核对、格式门禁、全新解压启动、目录探测及单实例检查通过。
- 语音核心沿用本机已现场验收的基线：豆包 v0.9.3.20 与搜狗组合落字正常，结束后回到搜狗。

## 使用边界

语音期间仍可能切到豆包；本版解决的是结束后恢复，不是全程不切换。
只在原窗口/PID/TID 仍在前台且当前仍是豆包时恢复；恢复接口作用于当前桌面，可能影响其他窗口。
主动改选豆包与自动切换无法区分；强制结束进程不能保证恢复。
豆包的非公开 RPC 可能随版本改变，其他输入法及应用组合需实测。本程序未做数字签名。
